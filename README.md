# ClawBrief 🐾

Web daily brief powered by Markdown data.

## Structure

- `data/YYYY-MM-DD.md` → daily source data
- `index.html` → web renderer

## Publish (GitHub Pages)

1. Push this repo to GitHub.
2. In GitHub repo settings, enable Pages from branch `main` / root.
3. Site URL will be:
   - `https://cyberpandame.github.io/ClawBrief/`

## Daily cadence

- Recommended push time: **09:00 UTC**
